# MySite: Personal Website Layout

An early personal website built with HTML and CSS. The page introduces Jordan Cooke through a hero area, profile section, skills section, and contact link.

## Problem and approach

The project explores how to organize a personal introduction as a single static page. Layout and visual hierarchy are implemented directly in CSS, keeping the site independent of a frontend framework or build system.

## Repository contents

| Path | Purpose |
| --- | --- |
| [index.html](index.html) | Page structure, section content, navigation links, and email contact link. |
| [css/styles.css](css/styles.css) | Typography, spacing, colors, image placement, and skill-row layout. |
| [images/](images/) | Cloud and mountain images used by the page. |
| [CSS - My Site Images/](CSS%20-%20My%20Site%20Images/) | Additional supplied image assets. |

The page also uses Google Fonts. The contact button opens an email client through a `mailto:` link.

## View locally

Open `index.html` in a browser, or start a static server from the repository root:

```bash
python3 -m http.server 8000
```

Visit `http://localhost:8000`.

## Portfolio focus and current scope

HTML page structure, CSS positioning, typography, and static asset organization. The page still contains placeholder text, empty image references, and generic social links; it documents a layout exercise rather than a finished professional profile.
